# Dashboard de Vendas Xbox Game Pass - Excel
Este projeto foi desenvolvido como parte do desafio prático **"Criando um Dashboard de Vendas do Xbox com Excel" do curso Santander - Excel com Inteligência Artificial na DIO**. O objetivo é transformar dados brutos de assinaturas em insights visuais que facilitem a tomada de decisão.

## Visão Geral do Projeto
O dashboard analisa o desempenho de vendas das assinaturas do Xbox Game Pass, segmentando os dados por tipos de planos (Core, Standard, Ultimate) e adicionais (EA Play e Minecraft Season Pass). A ferramenta permite identificar quais planos geram mais receita e o comportamento de renovação dos usuários.

## Estrutura do Arquivo
A solução foi construída utilizando uma arquitetura de três camadas para garantir a integridade e organização dos dados:

* **Bases:** Dados brutos contendo ID do assinante, nome, plano, tipo de assinatura (mensal, trimestral, anual), preços e cupons de desconto.
* **Cálculos:** Camada intermediária onde os dados são processados para responder a perguntas de negócio, como faturamento total de planos anuais e contagem de passes por categoria.
* **Dashboard:** Interface visual e amigável que apresenta os KPIs (Indicadores Chave de Desempenho) consolidados.

## Perguntas de Negócio Respondidas
* Qual o faturamento total das vendas de planos anuais?
* Como o faturamento de planos anuais se divide entre assinaturas com e sem renovação automática?
* Qual o volume total de assinaturas de complementos (EA Play e Minecraft) por tipo de plano?

## Tecnologias e Técnicas Utilizadas
* **Microsoft Excel:** Funções avançadas, Tabelas Dinâmicas e Gráficos.
* **Data Cleaning:** Tratamento de dados brutos para análise.
* **UX/UI Design:** Aplicação de hierarquia visual e cores temáticas (Xbox Brand) para facilitar a leitura.
* **IA para Análise:** Utilização de inteligência artificial para otimização das fórmulas de faturamento e validação de lógica de negócios.
